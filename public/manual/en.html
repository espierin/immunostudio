1. Start and understand your workspace

Open ImmunoStudio online, or start the local version with Start-ImmunoStudio.cmd. The local address is normally http://127.0.0.1:5180/. The local version adds native Office and video exporters.

New projects start in 2D, with the Default illustration style. English is the initial interface language. A previously selected language is remembered. Choose English or Nederlands in the header; this does not translate text inside your illustration or change your object names.

  • Header: project name, global Labels switch, 2D/3D switch, language, New, Open, Project and Export.
  • Left: library, search, categories and import (+).
  • Centre: the drawing page in 2D; a rotatable scene and timeline in 3D.
  • Right: Properties and, in 2D, Drawing. Hover over icons for explanations.

2D and 3D are separate parts of the same project. Switching modes keeps your work but does not automatically convert or add objects. A new 3D scene has no membrane until you explicitly add one.

2. First illustration: step by step

  1. Enter a meaningful project name in the header.
  2. Stay in 2D. Search the Basic elements library, or select a category.
  3. Click an element card to place it on the page.
  4. Choose Select or Move and drag it to the desired position.
  5. Use a corner handle to resize it. Use the round handle above the selection, or Rotate, to change its angle.
  6. Open Properties to enter exact X/Y, width, height and rotation values.
  7. Add a text label with Text; click the page, then edit the text in Properties.
  8. Choose an illustration style in Properties → Illustration style.
  9. Click Project to download an editable backup, then Export for the finished figure.

The library contains 190 curated individual elements, rather than complete teaching figures or tables. Search terms may be Dutch or English; source titles are retained.

2a. Home, commands and a cleaner workspace

The opening page offers Continue your project, Open project and three starting points: a blank canvas, a membrane with an attached receptor, and editable tissue layers. The current workspace is the locally saved project on this device, not a cloud project list. Starting an example while artwork exists offers a download and asks you to confirm replacement. Click the ImmunoStudio brand to return Home at any time.

  • Ctrl+K or F3: search commands by English or Dutch name. Use arrow keys, Enter and Escape. Unavailable actions are disabled.
  • Context bar: select an object for duplicate, mirror, layer, lock and sculpt actions. Multiple selection adds grouping and alignment.
  • Favorites: click the star beside a library element, then Favorites to show your saved choices. Stars are remembered in this browser.
  • F9 / Focus mode: hide or restore side panels. Search Reset workspace layout if you want to restore the default layout and floating menu placement.
  • 1 / Fit page and 2 / Fit selection: navigate without resizing artwork. Fit selection also accounts for rendered curve bounds.
  • Drawing → Page format: choose 16:9, square or an A4 aspect ratio; object positions and sizes remain editable. These presets define illustration dimensions, not print DPI.
  • Ctrl+S: download a portable project backup. Automatic local browser saving continues separately.

Design references: Inkscape welcome and command palette, Blender menu search, and BioRender context actions. ImmunoStudio uses its own vector graphics and implementation.

2b. Pathway building blocks

In 2D, choose the Pathway elements library tab. The first set contains 35 original schematic symbols: proteins, receptors, ligands, enzymes, metabolites, drugs, ions, genes, DNA/RNA, complexes, entity sets, multimers, unknown entities, reaction/process symbols, compartments and regulation connections. Filter by category or search using English or Dutch terms. Click a card to place an individual element. View the complete symbol gallery and download individual SVG files.

  1. Select a symbol and open Properties → Pathway building block.
  2. Edit Name to change both the scene name and visible label. Long visible labels may be shortened; full labels remain in metadata.
  3. Set State / modification, for example P, active or inactive. A state badge is displayed. No biological state is inferred automatically.
  4. Set Cell compartment and Stoichiometry. Database IDs use one database:identifier per line, for example UniProt:P31749. Complex/set/multimer members can be listed under Components (metadata).
  5. Move, rotate, resize and edit vector nodes normally. Label/state changes preserve your custom shape geometry. Restore standard symbol rebuilds the symbol from its metadata; Undo reverses the reset.

Compartments are placed behind other elements. The membrane library entry creates a native bilayer that supports Bézier editing and sculpting. Other compartment shapes are ordinary editable SVGs.

Save an .immuno project to preserve geometry and all pathway metadata. SVG symbols also carry metadata that ImmunoStudio can recognize when reimported. Source labels are illustration content and do not change with the interface language. Global Labels hides text in display/export while preserving the stored metadata.

This is the building-block phase: Reactome/WikiPathways class mappings are prepared, and database search is available from the Pathways menu. Choose Place on drawing page in a search result to import editable pathway elements. Connection symbols are standalone drawings; they do not yet attach automatically to molecular objects. IDs and component names are stored without online biological validation. The symbols are schematic and do not claim full SBGN or GPML conformance.

Reference for the class mapping: Reactome diagram specification and GPML schema.

2c. Search pathway databases

Choose Pathways → Search pathways… in the header. The same search opens from the 2D Pathway elements library, or through the command palette (Ctrl+K / F3, search for pathway). This searches public Reactome, WikiPathways and Pathway Commons information; it does not change your illustration.

  1. Enter a term, such as AKT1, interleuk, R-HSA-168256 or WP127.
  2. Choose Search by: Automatic combines pathway names and molecular matches, recognizing stable pathway IDs automatically. Pathway name matches words within names; Molecule name searches molecular entities contained in pathways; Pathway ID performs an exact stable-ID lookup.
  3. Choose All connected databases, Reactome, WikiPathways or Pathway Commons. The organism defaults to Homo sapiens; choose Mus musculus or All organisms when appropriate. An ID from another species will not match the human filter.
  4. Press Search. Each result shows its source, stable ID, organism and pathway name. Molecule searches also show the matching entity names. Expand Description where available, choose Open source to inspect the original pathway record in a new tab, or Copy ID to reuse the reference.
  5. Choose Show more results to reveal the next 20 results. Refine broad searches: each source returns at most 50 pathways and Reactome and Pathway Commons check up to 8 molecular entity matches. The status explicitly reports limits; this is not an exhaustive membership analysis.

Reactome is queried through its Content Service. Molecule matches are resolved to entities and then their containing low-level pathways. WikiPathways uses its official JSON index, including pathway names, species and molecular data-node labels; the first search downloads the index, then it is cached in memory for one hour. Partial molecular names can also match related names (for example AKT1S1), so check the displayed molecule matches. Automatic mode additionally considers WikiPathways descriptions and annotations.

Internet access is required. A failed source is reported separately while successful results remain visible. Retry or select the other database; Cancel stops the request and Escape closes the window. Search is separate from importing: choose Place on drawing page to load its editable elements.

Sources: Reactome Content Service · WikiPathways official search index.

Immunology and cell biology

Choose Pathways → Immunology and cell biology…, or expand this heading in the search window. Fifteen verified human reference pathways cover MHC-I antigen processing, MHC-II presentation, cross-presentation, ubiquitin/proteasome degradation, TCR, BCR, cytokines, complement, innate/adaptive immunity, autophagy, apoptosis, vesicle transport, membrane trafficking and ER stress/UPR. Hover for the source name and stable ID. Clicking a topic selects Reactome, an exact ID and Homo sapiens, then searches. These human references intentionally reset the organism filter. Change the source and search mode afterwards to explore related pathways.

Pathway Commons and KEGG

Pathway Commons is queried through its v2 API. Molecule searches use entity references and their indexed pathway memberships; up to 8 references and 50 pathways are explored. Exact IDs can be URIs such as netpath:Pathway_TCR, pc14:... or a bioregistry.io URI. Results show the underlying provider (for example NetPath or Reactome); source links open JSON records. Pathway Commons integrates other resources, so records may overlap with direct Reactome results. Coverage is mainly human, with incomplete coverage of other organisms.

KEGG is a clearly marked external website entry, from Pathways → KEGG (external website)… or the link under the form. It reuses your query and the human/mouse/reference-map prefix. An exact KEGG ID such as hsa04612 opens the antigen processing/presentation map directly. Theme shortcuts use related English keywords, without claiming equivalence between databases. Molecules may require a further gene/compound lookup on KEGG. Results remain on its website: the KEGG API lacks cross-origin browser support and has academic-use conditions. Local KGML file import is available through Import pathway file. No proxy or mirrored KEGG data is included.

The separate theme registry stores source IDs, species, original names and a verification date, allowing future immune/cellular additions based on established sources. Use Place on drawing page to import editable elements, as described in the next chapter.

References: Pathway Commons API · KEGG API conditions · KEGG antigen processing and presentation.

2d. Place an editable pathway

Open Pathways → Search pathways…, find a pathway and click its title or Place on drawing page. ImmunoStudio fetches the structured source data and builds separate native SVG objects on the 2D page. This creates editable molecules, compartments, labels and connections, rather than one flattened picture. The editor switches to 2D.

  1. On an empty page, the sheet size follows the imported diagram. With existing artwork, the pathway is appended below it and the page expands. Existing artwork is retained. Use Fit page to see the whole diagram.
  2. Click a molecule to select it. Move, rotate or resize it with the existing tools or Properties. Name changes also update the visible label. Source database IDs remain in Pathway building block.
  3. Figures and labels receive separate space and a readable font. Arrows attach to the figure outline and reroute when connected objects move, rotate, resize or mirror. Reactome reaction junctions and WikiPathways edge anchors retain their connections. To edit an arrow manually with Edit nodes, select it and choose Detach pathway arrow first.
  4. Undo reverses the entire insertion in one step. Later edits have their own Undo steps. Download a .immuno project to preserve the editable objects and their source metadata; reopening it does not need another database request.

Source layouts and limits

Reactome uses its diagram JSON with node and compartment bounds, reaction segments and molecular connectors. WikiPathways uses GPML coordinates, data nodes, groups, labels and interactions. Shapes and typography are converted schematically; the original styling is not reproduced exactly. Pathway Commons records derived from Reactome use the Reactome layout where available. Other Pathway Commons records use BioPAX entities, processes and control relations with an explicitly automatic layout, not an original source illustration.

Import does not manufacture missing biological relationships. Unsupported or absent source decorations may not be drawn. Inspect the original source for biological interpretation. Large imports are bounded to 4,000 objects per drawing page and a maximum sheet extent of 10,000 units; a request times out after 45 seconds. Choose a narrower subpathway if needed. Retrieval or validation errors are shown before any objects are inserted.

Import a pathway file, including KEGG

In the search window choose Import pathway file…. Supported files are WikiPathways GPML, Reactome diagram JSON and KEGG KGML (.xml or .kgml). Download KGML using the KEGG pathway page, then select your local file. Its entries and relation/reaction links become separate editable objects; KGML does not contain every decorative element in the original KEGG figure. Files are processed locally and are not uploaded. This does not add a KEGG API proxy or mirror.

Biological illustrations

New imports automatically recognize exact cell names and common cytokine, chemokine and membrane-protein symbols. Cell figures reuse the native receptor-free collection; fibroblasts, endothelial cells, epithelial cells and stem cells have separate schematic silhouettes. Open 2D → Pathway elements to place the same figures manually. Search for a name such as IL2, CXCL8, CCR7 or fibroblast. These are editable family cartoons, not experimentally determined molecular structures. Unrecognized names retain the source symbol; a pathway or process name is not converted into a cell. Additional family members can use a shared family silhouette with their original label. Existing diagrams are retained; import again to apply the new illustrations. New imports expand and separate dense layouts automatically. For an existing drawing choose Pathways → Improve pathway layout; select one pathway element first to restrict the command to that import, or leave the selection empty for all pathways. One Undo restores the previous layout. Older independent arrows are connected using their existing vector endpoints; reimporting uses explicit source connection IDs.

3. Select, move, resize and arrange in 2D

Click an element to select it. Shift-click to add or remove objects from the selection. Drag an empty area with Select to make a selection rectangle. A grouped element selects its group. Use Drawing → Select all, Deselect all, Invert selection or Unlocked objects for larger selections.

Move by dragging, by entering X/Y in Properties, or with the arrow keys. Arrow keys move one page unit; Shift+arrow moves ten. Rotate by dragging around the selection with Rotate, using the round rotation handle, or entering an angle in degrees. Shift constrains interactive rotation to 15° increments. Drawing also offers 90° left/right commands.

Library SVG elements keep their proportions when resized with corner handles. Shift also constrains resizing of other shapes. Exact width/height fields are available in Properties. If movement appears to jump, turn off Snap to grid in Drawing.

Properties → Locked prevents editing until you unlock the object. Use the scene list in Properties to select objects hidden behind others and to toggle visibility. Fit page restores the normal page view; Pan, zoom buttons and the mouse wheel change your view, not your artwork size.

4. Text, shapes and labels

Choose Text and click to place a label. Select it and edit its content, font size and colour in Properties. Draw Line, Arrow, Rectangle or Ellipse by dragging from a starting point to an ending point. Draw creates a freehand line. Properties exposes the relevant appearance controls for each object, such as fill, stroke, opacity and line width.

The global Labels checkbox switches illustration labels off or on for both display and export. Use it to make labelled and unlabelled versions without deleting the labels. A 3D object also has its own Show label option. Source text inside imported vector illustrations is not automatically translated when you change interface language.

Cells in 2D can have soft volume shading. Select a cell and use Volume shading in Properties to change that appearance. This is a vector shading effect; the separate 3D cell variant has actual depth.

5. Edit the points of a basic SVG element

  1. Add an SVG basic element and select it.
  2. Open Drawing and choose Edit nodes.
  3. Click the particular part you want to reshape: for example a cell outline, nucleus or molecular domain. An SVG can contain several independent parts.
  4. Drag blue anchor points to move the contour; drag orange Bézier handles to change curvature.
  5. Select a point and choose Add node to split the corresponding line or Bézier segment. The split initially preserves the curve.
  6. Return to Select to move the whole element. Use Undo if a contour changes unexpectedly.

The editor changes the embedded project copy and preserves the original library file. Existing transforms and other SVG parts are retained. Line, quadratic and cubic segments can be split. SVG arc endpoints can move, but arc splitting and a complete Inkscape-style node editor are not implemented. These controls edit vector illustration geometry, not atoms or a protein sequence.

5a. Sculpt cells and tissues

  1. Select a cell, tissue or membrane in 2D and open Sculpt & modifiers from the toolbar or Drawing tab.
  2. For a tissue with several cell outlines, first choose Edit nodes and click the particular cell boundary. Then choose Sculpt. Otherwise the largest filled contour is selected.
  3. Choose Push and pull, Inflate, Deflate or Local smooth. Drag near the edge. Radius controls the affected area in drawing-page pixels; Strength controls the deformation. Shift reverses dragging and inflation.
  4. Enable Deform interior structures to carry enclosed internal vector structures along, including a nucleus farther from the brush. Receptor groups remain rigid and turn with the membrane.

Drag the dark title bar to reposition the floating menu. Use − to minimize, the diagonal-arrow button to expand or compact, and × to close. Reopen it from the toolbar. A focused title bar also moves with arrow keys (Shift for larger steps). Position, size and collapsed sections are remembered.

Contour modifiers: Smooth softens the selected outline; Simplify reduces its points using the tolerance; Inset and Outset move the boundary inward or outward by the distance. Horizontal and vertical flips mirror the whole object. Undo reverses individual edits; Restore contour returns to the geometry before the first sculpt stroke or contour modifier. Work on individual vector parts: compound paths containing multiple subpaths are not sculpted as one outline. These are focused contour operations, not the complete Inkscape live-path-effect system.

5b. Attach molecules to a membrane

  1. Select the cell boundary or drawn membrane and click Use as membrane. For a specific tissue outline, choose that part with Edit nodes first.
  2. Select one or more separate molecule objects and click Attach selection. The molecule follows that contour and its axis remains perpendicular.
  3. Adjust Position along edge, Distance from edge and Anchor height in molecule in the floating menu. The default attachment point is centred horizontally and 80% down the molecule. Change it to match the actual transmembrane domain.
  4. Drag an attached molecule to move its anchor along the membrane. Use Other membrane side to reverse its orientation, or Detach to restore free movement and rotation.

Recognizable grouped receptors already inside a cell illustration follow automatically when sculpting that boundary. For a custom grouped receptor, first establish the cell boundary with Use as membrane, then select a receptor part with Edit nodes and choose Mark part as membrane molecule. This requires a separate SVG group near the boundary; ungrouped artwork may need to be imported as a separate object and attached.

Project files and local autosave preserve contour edits and attachments. SVG/PNG exports preserve the resulting shapes and poses. These 2D edits do not regenerate the separate 3D model.

5c. Give a line a membrane or tissue layer

  1. Draw a Line or freehand path, or select a rectangle or ellipse. Open Properties or the floating Sculpt & modifiers menu.
  2. Under Line construction and fill, choose Line only, Cell membrane, Endothelium, Skin / stratified epithelium, or Intestinal epithelium. Tissue is generated along the line: flat endothelial cells, three epithelial layers with flatter surface cells, or columnar intestinal cells with schematic goblet cells and an apical brush border.
  3. Independently switch Fill interior on or off and choose a Fill colour. An open curve is visually filled back to its starting point along a straight connection; it stays an open editable curve. On a closed ellipse, this fills the enclosed area. The tissue lining remains visible when interior filling is off.
  4. For tissue layers, set Layer thickness, Cell width and Side of the line. Use a thinner layer or a wider bend if the inner side of a tight curve overlaps.
  5. Choose Edit Bézier line to expose blue anchors and orange handles. Drag them freely beyond the original line box. Add node inserts an anchor without initially changing the curve, up to 31 anchors. A closed curve keeps its shared first/last anchor joined.
  6. Choose Sculpt to push, pull, inflate, deflate or smooth the curve. All generated cell walls, nuclei and apical details are rebuilt with it. Switch construction styles without redrawing the curve.

For existing SVG cells, Deform interior structures moves and deforms the enclosed nucleus and organelles with the cell boundary, including deeper parts of the cell. It applies to sculpting, Bézier node edits and contour modifiers; turn it off to edit only the boundary and its attached receptor groups. Parts outside a chosen closed outline stay in place, so editing one cell in a tissue does not warp every neighbouring cell. Generated membrane and tissue layers always follow their curve. All layers are schematic illustration patterns, not measured histology or simulations.

6. Draw membranes and convert a circle into a vesicle

Draw a membrane directly

  1. In 2D choose Membrane and drag across the page.
  2. Select the resulting bilayer.
  3. Drag its anchor points and orange handles to bend it.
  4. Use Properties to change membrane thickness.
  5. Choose Add curve point, or double-click the membrane, to add an anchor without initially changing the existing curve.

Convert a drawn shape

  1. Draw a line, freehand path, rectangle, circle or ellipse. For a circle, give an ellipse equal width and height in Properties.
  2. Select the shape and open Drawing.
  3. Click Convert to membrane.
  4. An open path becomes a membrane segment. A closed shape becomes a bilayer loop with an empty centre: a 2D vesicle.
  5. Adjust the curve and thickness. Undo restores the original drawing.

To create a spatial version, switch to 3D and click 3D from 2D drawing in Properties. This converts eligible SVG elements and membranes on the 2D page. A closed membrane becomes an ellipsoidal vesicle cutaway with two shells and lipid tails at the opening rim. Irregular closed loops currently use their bounding ellipse in 3D; their original 2D contour remains intact. Very long freehand paths are simplified when converted.

Lipid packing: each leaflet is filled independently along its own edge length. An outside bend can have more lipids than the inside bend. Head spacing is adjusted to keep both rows closely packed, including the seam of a closed loop. This updates automatically after curve edits, sculpting and membrane thickness changes; there is no required one-to-one pairing between the leaflets.

7. Work with 3D cells and molecules

Switch to 3D. Add a basic element for a rounded schematic volume, choose a built-in model under 3D models, import your own model, or use 3D from 2D drawing. Add vesicle creates a separate vesicle without adding a planar membrane.

Drag empty space to orbit the camera, right-drag to pan and use the wheel to zoom. Select an object and choose Focus selection to place the camera target on it. Default view restores the standard view. Properties → Camera & focus offers front/back/side/top/bottom views, orthographic or perspective projection and numeric zoom.

Use Move and the 3D handles, or enter X/Y/Z in Properties. Use Rotate and the rotation controls; additional X/Y rotations are in radians, while the displayed main rotation angle is in degrees. Scale is illustrative. Depth layer offers four preset levels plus free depth. A membrane-anchored model instead has a Position along membrane control and a depth position.

Cell volumes have a type-specific rounded rear and a flat front cut showing the original nucleus and organelles. Dendritic cells retain thin processes, erythrocytes and platelets are flattened, cardiomyocytes retain their elongated contour, and phagocytes have an asymmetric rear. Round lymphocytes remain relatively round. Volume depth changes their depth. Rounded volume and relief are schematic geometry options for SVG-derived models. They are not predictions of a protein's atomic structure.

Use Save to my library to reuse a model on this browser/device. GLB export is available for supported selected 3D models. A 3D variant remains linked to its 2D source ID to avoid duplicates; later edits to the 2D source do not automatically rebuild an existing 3D variant. To regenerate one, remove that 3D variant and run the conversion again.

8. Add and edit the 3D membrane

Enable Properties → Membrane → Show membrane, or choose the Membrane tool. A new scene leaves it off by default. Thickness, depth and rear fading control its appearance. Lipid heads cover the membrane surfaces; paired thin tails are shown at the physical outside perimeter rather than throughout the interior depth.

Choose Edit Bézier curve to expose anchors and handles. Drag them to bend the membrane. Add curve point splits the curve; anchored proteins follow its shape. Cross-section changes the visible cut. A membrane edge can look thin from a side or top view; rotate the camera to inspect it.

For supported proteins or imported structures, Attach to membrane / Detach from membrane switches anchoring. Imported models use their model origin as the manual anchor: inspect orientation, scale and the transmembrane boundary yourself. The reference channel has a membrane opening; arbitrary imported models do not automatically cut a matching pore.

Conformation is a schematic IgG hinge tool: select an IgG, choose Conformation, select its Fab arm and adjust the hinge angle. This is not general protein rigging or molecular dynamics.

9. Import SVG, GLB, PDB and mmCIF

Click + in the library. In 2D import a self-contained SVG. In 3D import SVG, GLB, PDB, CIF or mmCIF. Files are limited to 30 MB. Use independent vector SVGs without scripts or external images. A 3D SVG import initially remains a flat asset; use Build 3D volume when that control is offered.

Retrieve a structure from RCSB PDB

  1. In 3D select the PDB library tab and search by molecule name or PDB ID.
  2. Open a result. Choose biological assembly 1 or the asymmetric unit.
  3. Fetch the structure. If the assembly is unavailable, try the asymmetric unit.
  4. Inspect the rotating preview and select only the required chains.
  5. Choose van der Waals atom spheres or CA/P backbone.
  6. Add the selected chains, then check scale, orientation and any membrane anchor.

Some basic molecules have an Experimental structure panel with a checked PDB reference and an RCSB link. References can be fragments, complexes or a related species/isotype. Check species, allele, peptide and chain composition before using them. A reference is not an automatic exact identity match to the cartoon. Other molecules offer RCSB search.

Coordinates are converted from Å to nm. Missing domains are not reconstructed. The app does not simulate molecular dynamics or calculate a molecular solvent surface. RCSB search and retrieval require internet; imported project coordinates are stored with the project.

10. Illustration styles

Open Properties → Illustration style. The order is Default, UMC Utrecht, Nordic Light, Nordic Dark, EFI, Illustrated Light and Dark Presentation. Default is used for new projects. Styles alter illustration colours; the application interface retains its UMC Utrecht appearance.

Colour swatches let you adjust roles such as heads, tails, receptors, HLA, antibodies, background and labels. Individual colour overrides may take precedence; use Style colour to return an object to its style role. Import and JSON export allow stylesheet reuse. Save the project after creating a custom palette.

11. Animate a moving molecule: complete example

  1. In 3D add and select a molecule. Set Duration to 8 seconds.
  2. Open Properties → Animation & render. Choose 24 fps, Start frame 1 and End frame 192.
  3. Choose Selected object as Keyframe target. Keep Auto keying off while setting up the first poses.
  4. Move the timeline to time 0. Set the molecule's starting position and click Insert keyframe.
  5. Move the timeline to time 4 seconds. Move or rotate the molecule, then click Insert keyframe again.
  6. Click Play. The molecule moves between the poses; values are automatically calculated between keys.
  7. Scrub the timeline to inspect intermediate frames.
  8. In the key list, change a key's frame number to retime it, select its interpolation or click × to delete it.

Important: move the timeline first, then change the pose, then insert the key. Scrubbing evaluates existing keys and can replace an unkeyed pose. After setup, Auto keying records subsequent interactive camera/object transformations. Explicitly insert a key after other property changes when you need a guaranteed pose.

InterpolationResult
ConstantHold the earlier pose until the next key.
LinearChange values at a constant rate between keys.
Smooth · BézierEase into and out of the movement.

The interpolation on a key controls its outgoing segment. This is a Blender-like keyframe workflow with smooth easing, not Blender's full editable F-curve, NLA, constraint or rigging system. Object paths are determined by their keyed positions; no collision avoidance or physical movement is simulated.

12. Camera actions and combined animation

Choose Camera only as the target to keyframe the view without recording object poses. At the starting time, orbit/pan/zoom to the first view and insert a key. Move the timeline, change the view and insert another. Selected-object tracks and camera tracks can coexist. Scene and camera records all object poses and the view together; use independent targets when you want independent timing.

Focus selection establishes a target. Camera & focus → Follow-me moves the camera with its anchor; Look at focus aims at the anchor; Free camera removes that following behaviour.

Set the view, target and render range before creating an action. A camera action replaces camera-only keys within that range, while object tracks remain. Use Undo to restore previous keys. Loop repeats playback over the render range. Frame 1 corresponds to time zero; at 24 fps, frame 97 corresponds to 4 seconds.

13. Export for figures, Office and video

First download an editable Project backup. Exported images and videos are finished outputs, not substitutes for the project. Set the style and Labels switch before export.

FormatRecommended use and availability
PNGOnline/local. Raster figure at 1920 or 3840 px wide; optional transparent background. 2D exports the page; 3D renders the current view.
SVGOnline/local. Entire native 2D page. In 3D it exports the selected source vector, not the entire rendered scene.
EMF / WMFLocal Inkscape exporter. Useful for PowerPoint/Word. 2D remains vector where supported; 3D embeds a raster image.
MP4 / AVILocal FFmpeg exporter. MP4 uses H.264; AVI uses Motion JPEG. Render settings control range, rate and dimensions.
GIFLocal. 12 fps, 800 px wide, maximum 15 seconds, looping.
WebMOnline/local if the browser supports recording. Real-time recording; keep the tab active for reliable capture.
PNG frame sequenceOnline/local. ZIP with a numbered image for every selected output frame, suitable for external video editing.

Fonts: EMF/WMF can convert text to vector outlines. This preserves letter appearance but does not embed editable fonts. Keep the source project for text editing. Office versions may simplify gradients; SVG or PNG can be preferable when appearance is more important than metafile editing.

Render settings

  1. In Animation & render, choose 12, 24, 25, 30, 50 or 60 fps.
  2. Set Start frame, End frame and Frame step. Use step 1 for every frame.
  3. Set render width (320–3840) and height (240–2160). Use even dimensions for conventional video encoders.
  4. Open Export and verify the settings. Choose PNG sequence, WebM or a local video format.
  5. Wait for completion; use Cancel when the progress panel offers it.

Maximum output is 1801 frames per job. Frame steps above 1 omit frames: PNG filenames retain their original frame numbers, while encoded playback uses the selected fps and therefore becomes shorter. PNG and native video render chosen frames individually; WebM records in real time. Video settings do not change the separate still-image size selector.

On GitHub Pages, disabled native export buttons are expected. Transfer a downloaded .immuno project to the local version for EMF/WMF or MP4/AVI/GIF. In Word or PowerPoint, insert the exported file using Insert → Pictures, or Insert → Video for a supported movie format.

14. Save, reopen and transfer projects

The editor automatically saves in browser storage on the current device. Wait for the saved indicator. This is not a cloud account or a shared project folder. Online and local versions have separate browser storage; another browser or device will not automatically see your project.

  1. Click Project to download an editable .immuno file.
  2. Keep versioned copies before major edits.
  3. Use Open and select that file to restore it, including embedded assets and animation keys.
  4. To transfer between online and local versions, download from one and open in the other.
  5. Before choosing New and starting an empty scene, download the current project if you want to keep it separately.

Clearing browser/site data can remove autosaves and the personal model library. File backups remain your portable copy. Use Undo/Redo for recent edits; the undo history is limited and is not a version archive.

16. Troubleshooting and limits

I cannot move an element.
Check the active mode and tool. Select the object, unlock it in Properties, and use Move. In 3D, empty-space dragging rotates the camera.
I cannot find a hidden element.
Use the scene list in Properties, enable its visibility and adjust its stacking/depth order.
My 2D drawing is absent in 3D.
Switching modes does not convert it. Use 3D from 2D drawing. Only eligible vectors and membranes are converted; plain text and native primitive shapes are not all converted directly.
A 3D variant does not reflect my newest 2D edits.
Existing variants are retained. Delete that variant and regenerate from the updated 2D source.
The membrane is missing.
Enable Show membrane in 3D, or draw/convert a membrane in 2D. The two modes have separate membrane content.
Animation jumps or a pose disappears.
Check keyframe target, key timing and interpolation. Insert the starting pose and each edited pose. Scrubbing evaluates saved keys; use Undo to recover an unkeyed edit.
A PDB structure has extra copies.
Review assembly choice and chain selection. Import only the needed chains. Do not assume every chain is part of your intended illustration.
A native exporter is unavailable.
Use the local starter and ensure its Inkscape/FFmpeg support is available. Online, use SVG/PNG, WebM or PNG frames.
Everything looks slow.
Reduce the number of complex volumes or imported atoms, use backbone representation and export a short low-resolution range first.

All 190 basic elements have been checked for valid finite 3D geometry, but their schematic volumes do not establish biological identity. No automatic missing-region reconstruction, full molecular surface computation, general rigging or molecular dynamics is provided.
